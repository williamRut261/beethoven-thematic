# Beethoven Thematic — independent research only

This public repository contains a research-only adaptation of the Beethoven 6.6 rule tree. It compares its original allocation structure with leveraged thematic alternatives and drawdown-limiting overlays. **No broker accounts, credentials, order placement, schedules or live execution.**

The source is user-provided. Results use public historical adjusted closes, are preliminary and do not establish Composer parity or tradable execution quality. All strategies remain isolated from A15 and FSupertrend.
